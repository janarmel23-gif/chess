Connect Firebase

Online play, Google sign-in and chat run on Firebase — it is free for this scale. Paste your web app config below; it is stored in this browser only.

  1. Open console.firebase.google.com and create a project.
  2. Build → Authentication → Get started. Enable Google and Email/Password.
  3. In Authentication → Settings → Authorized domains, add your GitHub Pages domain (e.g. yourname.github.io).
  4. Build → Firestore Database → Create database (production mode), then paste the rules shown below.
  5. Project settings → Your apps → Web, register the app and copy the firebaseConfig object.
